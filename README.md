# paschalidoud.github.io
Personal website

## Editing

Pages are plain HTML. The shared parts are generated by `build.py`:

| Block between `<!-- start X -->` / `<!-- end X -->` | Source |
| --- | --- |
| `head` (title, description, social cards, stylesheets, scripts, JSON-LD) | `PAGES` in `build.py` |
| `header`, `footer` (menu, profile links, analytics) | `build.py` |
| `publication list` | `publications_data.py` |

```
python3 build.py          # regenerate the pages
python3 build.py --check  # exit 1 if a page is out of date
```

Run `build.py` after changing `publications_data.py`, `common.css`,
`style.css`, `style_project_page.css`, `site.js` or `build.py` itself. The
stylesheet and script URLs carry a content hash, so this is also what makes
browsers pick up your CSS/JS changes.

To add a paper, add a `Paper(...)` to `publications_data.py` (use
`selected=True` to also show it on the home page). Each paper's anchor comes
from its BibTeX key, so `publications#wu2026neurips-bibtex` opens that
entry's BibTeX.

Stylesheets: `common.css` (colour tokens, dark mode, BibTeX blocks) is shared
by every page, `style.css` styles the main pages and `style_project_page.css`
the project pages. `site.js` handles the Abstract/BibTeX toggles and the copy
button.
